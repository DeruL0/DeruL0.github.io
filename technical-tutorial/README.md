# 五线高级技术教程

这套教程从 2026-06-28 重新开始。旧的聊天式教程不计入正式进度。

目标不是罗列论文、关键词和待办事项，而是按照教材顺序，逐步建立五棵彼此独立、内部连续的知识树：

1. CT 重建与工业 CT
2. 几何处理
3. AI Infrastructure 与 GPU 训练系统
4. 可微、可训练三维渲染
5. DirectX 12、游戏引擎架构与实时渲染

## 文件组织

```text
technical-tutorial/
├─ README.md
├─ CURRICULUM.md
├─ FORMAT.md
└─ days/
   └─ day-NNN/
      ├─ 00-index.md
      ├─ 01-ct.md
      ├─ 02-geometry-processing.md
      ├─ 03-ai-infrastructure.md
      ├─ 04-differentiable-rendering.md
      └─ 05-directx12-engine-rendering.md
```

每天建立一个 `day-NNN` 目录。五条线分别保存为五个文件，不把内容混成一个项目。

## 固定学习方式

每篇章节都按照 [FORMAT.md](FORMAT.md) 的固定八段故事链编写：

```text
现实任务
→ 最直接的办法
→ 旧办法暴露的问题
→ 关键抽象为什么出现
→ 正式模型怎样一步步建立
→ 完整例子
→ 真实系统如何实现
→ 本章落点与下一问题
```

固定的是理解顺序，不是摘要栏目。概念和公式必须从前文的问题自然产生；“练习”只确认已经讲过的内容，不会代替讲解。
