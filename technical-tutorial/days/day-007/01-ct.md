# CT 第 7 章：为什么真实 X 射线穿过厚物体后会“变硬”

## 1. 从一个真实任务开始

上一章从 photon counts 建立了 Poisson likelihood，但仍假设每条 ray 的期望 count 可以写成

\[
\lambda_i=b_i e^{-(Ax)_i}+r_i.
\]

这相当于假设所有 X 射线 photons 具有同一种能量，材料衰减系数是一个固定数。真实 X-ray tube 发出连续能谱，低能 photons 更容易被吸收，高能 photons 更容易穿透。同一块材料对不同能量的线性衰减系数 \(\mu(E)\) 不同。

今天的工业任务是扫描一个厚金属与树脂混合零件。即使几何、计数噪声和迭代 solver 都正确，重建中仍出现中心偏暗的 cupping、金属之间的暗带和材料 CT number 随厚度变化。要理解这些现象，必须把能谱、材料与 scatter 放回 expected-count model。

## 2. 最直接的办法，以及它为什么不够

最直接的修正是在 log projection 上拟合一个多项式：

\[
p_{\rm corrected}
=
c_1p+c_2p^2+c_3p^3.
\]

用一组同材料、不同厚度的 calibration plates，可以让校正后的 \(p\) 近似与厚度线性。对单一材料和固定 spectrum，这种方法便宜且实用。

但混合物体中的一条 ray 可能先穿过铝、再穿过钢和树脂。不同材料的 \(\mu_m(E)\) 曲线不同，单变量 \(p\) 无法唯一表示各材料 path lengths。对水或铝标定的 polynomial，不会自动适用于另一种组合。

另一个常见做法是在重建后做 cupping correction。它能调整低频 shading，却不能恢复由 projection inconsistency 形成的条纹，也无法区分 beam hardening 与 scatter。新的模型必须从 detector count 前向产生，而不是从伪影图像倒猜。

## 3. 关键想法是怎样被引出来的

设 source 在能量 \(E\) 处发出强度 \(S(E)\)，detector response 为 \(\eta(E)\)。一条 ray 穿过多个材料，每种材料 path length 为 \(\ell_m\)。该能量的透射比例为

\[
\exp\left[
-\sum_m\mu_m(E)\ell_m
\right].
\]

detector 不分别报告每个能量，而是把所有能量贡献积分：

\[
I
=
\int
S(E)\eta(E)
\exp\left[
-\sum_m\mu_m(E)\ell_m
\right]dE.
\]

低能成分随着厚度增加被优先删除，穿出物体的剩余 spectrum 平均能量升高，也就是 beam hardening。由于指数在能量积分内部，负对数不能把它变成固定系数的材料 path-length 和。

scatter 则是另一种破坏。它向 detector pixel 加入没有沿该直线路径传播的 photons，因此主要信号与 scatter 在 count domain 相加，而不是在线积分域相加。

## 4. 一步一步建立正式模型

把能量离散成 bins \(k=1,\ldots,K\)，令空场中每个 bin 的有效 photon weight 为 \(s_{ik}\)。多材料 primary expectation 为

\[
\lambda_i^{\rm primary}
=
\sum_{k=1}^{K}
s_{ik}
\exp\left[
-\sum_{m=1}^{M}
\mu_{mk}\ell_{im}
\right].
\]

加入 scatter/background \(r_i\)：

\[
\lambda_i
=
\lambda_i^{\rm primary}+r_i.
\]

观测仍可写成

\[
n_i\sim\operatorname{Poisson}(\lambda_i).
\]

单材料时，令 path length 为 \(L\)，空场强度为

\[
I_0=\sum_ks_k.
\]

负对数 projection 为

\[
p(L)
=
-\log
\frac{\sum_ks_ke^{-\mu_kL}}
{\sum_ks_k}.
\]

其斜率是 hardened spectrum 下的加权平均 attenuation：

\[
\frac{dp}{dL}
=
\frac{
\sum_ks_k\mu_ke^{-\mu_kL}
}{
\sum_ks_ke^{-\mu_kL}
}.
\]

随着 \(L\) 增大，高 \(\mu_k\) 的低能 bins 更快消失，斜率通常下降。于是 \(p(L)\) 是向下弯曲的，而不是固定 \(\bar\mu L\)。

多材料 reconstruction 可以把每个 voxel 表示为 material coefficients \(x_m\)，ray path 为

\[
\ell_{im}=(A x_m)_i.
\]

Poisson objective 仍是

\[
D(x_1,\ldots,x_M)
=
\sum_i
\left[
\lambda_i-n_i\log\lambda_i
\right].
\]

对某材料 path length 的 primary derivative 为

\[
\frac{\partial\lambda_i}{\partial\ell_{im}}
=
-\sum_k
s_{ik}\mu_{mk}
\exp\left[
-\sum_{m'}\mu_{m'k}\ell_{im'}
\right].
\]

再通过 \(A^{\mathsf T}\) 返回 material volumes。单一积分 detector 的一条测量通常不足以唯一分解多个材料；dual-energy、photon-counting energy bins、segmentation constraints 或材料先验提供额外信息。

## 5. 跟着一个完整例子走到底

考虑只有两个能量 bins 的 toy spectrum，权重各为 0.5。单一材料在低能和高能处衰减分别为

\[
\mu_1=0.5\ \mathrm{cm}^{-1},
\qquad
\mu_2=0.1\ \mathrm{cm}^{-1}.
\]

归一化空场 \(I_0=1\)。厚度 \(L=1\ \mathrm{cm}\) 时：

\[
I(1)
=
0.5e^{-0.5}+0.5e^{-0.1}
\approx0.7557,
\]

\[
p(1)
=
-\log0.7557
\approx0.280.
\]

若简单使用平均 attenuation

\[
\bar\mu=0.3,
\]

线性模型预测 \(p=0.3\)，误差还不大。

厚度增加到 \(L=5\ \mathrm{cm}\)：

\[
I(5)
=
0.5e^{-2.5}+0.5e^{-0.5}
\approx0.3443,
\]

\[
p(5)
\approx1.066.
\]

线性平均模型却预测

\[
\bar\mu L=1.5.
\]

effective attenuation 已从约 0.280 降到

\[
\frac{1.066}{5}
\approx0.213.
\]

若重建器仍假设 \(\mu=0.3\)，它会把测得的 \(p=1.066\) 解释成

\[
\widehat L
=
\frac{1.066}{0.3}
\approx3.55\ \mathrm{cm},
\]

明显低估真实 5 cm。物体中心 rays 通常路径更长，因此中心被低估得更多，形成 cupping。

再加入归一化 scatter \(r=0.02\)，detector count 变为

\[
I_{\rm measured}=0.3443+0.02=0.3643,
\]

负对数降到

\[
-\log0.3643\approx1.010.
\]

scatter 进一步让衰减看起来更低。使用已知两能谱 forward model反求 \(L\)，则可从 \(I=0.3443\) 恢复接近 5 cm；它不是在重建图上抬高中心，而是修正 count 产生机制。

## 6. 回到真实系统：程序实际上怎样工作

多能 CT 模型应明确分层：

~~~text
tube spectrum and filtration
detector energy response
material attenuation tables mu_m(E)
ray-wise material path lengths
→ polychromatic primary counts
scatter/background model
→ expected detector counts
→ Poisson likelihood
→ material or attenuation reconstruction
~~~

spectrum 可由物理模拟、厂商信息或 calibration phantom 估计。attenuation tables 需要与材料密度和能量单位一致。energy bins 太少会产生离散误差，太多则增加 projector cost；可预计算 basis-material exponential lookup 或使用 GPU vectorization。

scatter estimate 可来自 Monte Carlo、beam-stop/interpolation、kernel-based model 或联合优化，但必须记录它是固定校正还是可训练变量。若 scatter 与 object density 同时自由，二者容易互相补偿，造成不可辨识。

对 CTGS，可让每个 Gaussian 携带 basis-material coefficients，解析或数值计算每条 ray 的 material line integrals，再经 spectrum integration 生成 counts。先验证单材料 polychromatic forward，再扩展多材料，避免同时调表示与物理模型。

工程诊断应按厚度、材料组合和 detector 位置比较 measured/predicted counts。若 residual 随 path length 系统弯曲，说明 spectrum或 attenuation model 有误；若 residual 是宽而平滑的 detector pattern，scatter更可疑。

## 7. 容易走错的岔路

把 beam hardening 当成固定 additive bias 不正确。它随 spectrum、材料和 path length 非线性变化，换 tube voltage 或 filtration 后校正也会改变。

单材料 polynomial correction 在 calibration phantom 上很好，不代表多材料零件可靠。不同材料组合可以产生相近总 count，却对应不同路径。

scatter correction 后出现负 primary count，说明估计或校准不一致，不能简单 clamp 后假装物理成立。clamp 会改变 likelihood 并隐藏模型问题。

同时优化 spectrum、scatter 和任意 voxel attenuation 可能让 loss 很低，却无法唯一解释数据。必须使用 calibration、低维 basis 或额外能量测量约束。

最后，多能模型仍不能自动解决 detector saturation、金属完全 photon starvation 和截断投影。没有有效 counts 的 rays 仍属于不完整数据问题。

## 8. 本章落点、验证与下一章

本章把单能 Beer-Lambert 扩展为 spectrum integral。低能 photons 被优先吸收，使 effective attenuation 随厚度下降；scatter 在 count domain 额外加 photons。多能 expected-count model与 Poisson likelihood共同解释了 cupping 和材料相关条纹为何不是简单图像 bias。

在 CT Framework 中，本章对应 spectrum、detector response、material attenuation、scatter 与 polychromatic projector模块。在 CTGS 中，它对应 basis-material Gaussian 参数和 count-domain training，而不是对 log projection 做无物理含义的颜色合成。

本章的 90 分钟验证是复现两能量例子，绘制 \(L=0\) 到 10 cm 的 \(p(L)\) 与线性 \(\bar\mu L\)，再分别加入 0、0.01 和 0.02 scatter。预期是曲线随厚度向下弯，scatter 让厚区 apparent attenuation 进一步下降；用单一 polynomial 在材料 A 上拟合后换材料 B，应出现系统残差。

下一章会进入金属伪影与不完整测量：当部分 detector counts 饱和、为零或被截断时，哪些 rays 应进入 likelihood，哪些只能被 mask、补全或由先验约束，以及 metal trace 中的信息缺失如何沿反投影形成条纹。
