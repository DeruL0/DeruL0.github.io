# CT 第 4 章：当 FDK 不再足够时，重建为什么变成一个优化问题

## 1. 从一个真实任务开始

上一章用 FDK 从圆轨迹 cone-beam 投影快速生成三维体，也明确了它的边界：噪声、有限 detector、cone angle、轨迹不完整和几何失配都会留下结构化残差。现在考虑一个工业检测任务：零件中有尺寸接近分辨率极限的小孔，扫描角度受机械遮挡而缺失一段，FDK 中出现条纹与轴向模糊。我们不能重新扫描，却要给出一个既符合现有测量、又不会被缺失角度任意放大的体数据。

物理链仍从采集开始。负对数投影 \(y\) 近似由衰减体 \(x\) 经过 cone-beam forward operator \(A\) 产生：

\[
y=Ax+\varepsilon.
\]

\(\varepsilon\) 汇总量子噪声、预处理误差和暂未建模的物理效应。FDK 直接把 \(y\) 映射为图像；迭代重建则反复问：当前体 \(x\) 重新投影后，与实际测量还有多少不一致？哪些变化由数据支持，哪些必须由先验选择？

## 2. 最直接的办法，以及它为什么不够

最直接的迭代目标是只最小化投影残差：

\[
\min_x \frac12\|Ax-y\|_2^2.
\]

它比 FDK 更灵活，因为可以使用真实 cone-beam geometry、缺失 view mask 和任意 projector。若数据完整、噪声低且 \(A\) 条件良好，最小二乘可以恢复合理结果。

但有限角和稀疏角意味着某些体变化几乎不改变已采集投影。设存在方向 \(z\) 满足 \(Az\approx0\)，那么 \(x\) 与 \(x+cz\) 都产生相似数据。优化器可以沿这些 near-null-space directions 放大噪声，投影残差继续下降，图像却出现条纹和振荡。

甚至在测量方程有唯一最小二乘解时，小的投影误差也可能经病态逆放大。问题不是迭代次数不够，而是“最符合数据”并没有充分定义我们希望的物体。必须显式加入对解的偏好，并说明这种偏好会牺牲什么。

## 3. 关键想法是怎样被引出来的

迭代重建的关键抽象是把重建拆成两部分：data fidelity 衡量是否解释测量，regularizer 在数据无法区分的解之间作出选择。

\[
\min_x
\underbrace{D(Ax,y)}_{\text{符合测量}}
+
\lambda
\underbrace{R(x)}_{\text{选择稳定解}}.
\]

这不是用先验“替代数据”。当某个方向被测量强约束时，data term 主导；当某个方向位于近零空间时，regularizer 防止任意振荡。\(\lambda\) 控制二者的尺度平衡。

最简单的 \(R(x)=\tfrac12\|x\|_2^2\) 偏好能量较小的解，得到 Tikhonov regularization。它便于推导，却会压低整体幅值。更符合图像结构的选择包括梯度平方、total variation、非局部先验和 learned denoiser；但理解它们之前，必须先看清正则化如何改变线性系统。

## 4. 一步一步建立正式模型

先考虑加权二次 data term：

\[
D(x)
=
\frac12(Ax-y)^{\mathsf T}W(Ax-y).
\]

\(W\) 可以降低坏 pixel、缺失 view 或高方差测量的影响。在理想独立 Gaussian noise 下，它常与测量 covariance 的逆相关。

加入二次正则 \(R(x)=\tfrac12\|Lx\|_2^2\)，其中 \(L=I\) 表示幅值惩罚，\(L\) 也可是一阶差分。目标为

\[
\Phi(x)
=
\frac12\|Ax-y\|_W^2
+
\frac{\lambda}{2}\|Lx\|_2^2.
\]

为了让优化器知道怎样修改体，求梯度：

\[
\nabla\Phi(x)
=
A^{\mathsf T}W(Ax-y)
+
\lambda L^{\mathsf T}Lx.
\]

第一项把投影残差通过伴随返回体空间，第二项把违反先验的结构返回体空间。令梯度为零得到 normal equation：

\[
(A^{\mathsf T}WA+\lambda L^{\mathsf T}L)x
=
A^{\mathsf T}Wy.
\]

真实 CT 不会显式形成 \(A^{\mathsf T}A\)。conjugate gradient、LSQR 或 gradient-based solver 只需反复调用 forward、adjoint、\(L\) 和 \(L^{\mathsf T}\)。一个最基本的更新是

\[
x^{k+1}
=
x^k-\tau_k
\left[
A^{\mathsf T}W(Ax^k-y)
+
\lambda L^{\mathsf T}Lx^k
\right].
\]

衰减系数物理上非负，因此还可在每步后投影到

\[
x\ge0.
\]

这会把问题变成 constrained optimization。非负性不是为了让图像好看，而是排除不符合理想线性衰减模型的解；若预处理造成负 line integral，仍应先检查数据模型。

## 5. 跟着一个完整例子走到底

继续使用第 1 章的三个 voxel、两条射线系统：

\[
A=
\begin{bmatrix}
1&1&0\\
0&1&1
\end{bmatrix},
\qquad
y=
\begin{bmatrix}
3\\3
\end{bmatrix}.
\]

没有正则时，方程要求

\[
x_1+x_2=3,
\qquad
x_2+x_3=3.
\]

所以所有

\[
x=
\begin{bmatrix}
3-t\\t\\3-t
\end{bmatrix}
\]

都能产生零残差。数据无法判断中间 voxel 应该是 0、2 还是 3。

现在取 \(W=I\)、\(L=I\)、\(\lambda=1\)。normal equation 为

\[
(A^{\mathsf T}A+I)x=A^{\mathsf T}y.
\]

逐项写出：

\[
\begin{bmatrix}
2&1&0\\
1&3&1\\
0&1&2
\end{bmatrix}
\begin{bmatrix}
x_1\\x_2\\x_3
\end{bmatrix}
=
\begin{bmatrix}
3\\6\\3
\end{bmatrix}.
\]

由对称性令 \(x_1=x_3=a\)、\(x_2=b\)，得到

\[
2a+b=3,
\qquad
2a+3b=6.
\]

相减可得 \(b=1.5\)，进而 \(a=0.75\)。所以

\[
x_\lambda=
\begin{bmatrix}
0.75\\1.5\\0.75
\end{bmatrix}.
\]

它的预测投影是

\[
Ax_\lambda=
\begin{bmatrix}
2.25\\2.25
\end{bmatrix},
\]

没有完全拟合 \(y\)。正则化用 \(0.75\) 的 residual bias 换取较小的解范数和唯一性。若减小 \(\lambda\)，解会更接近某个零残差成员；但当 \(\lambda\to0\) 时，究竟选择哪一个成员又取决于算法和初始化。这个例子明确展示了正则化不是免费恢复信息，而是可控地选择信息缺失处的答案。

## 6. 回到真实系统：程序实际上怎样工作

工程模块应把物理模型、目标函数和 solver 分开：

```text
MeasurementModel
├─ forward(x, geometry)
└─ adjoint(r, geometry)

DataFidelity
├─ preprocessing / weights W
├─ value(Ax, y)
└─ projection-space gradient

Regularizer
├─ value(x)
├─ gradient or proximal operator
└─ parameter lambda

IterativeSolver
├─ step rule / line search
├─ constraints
└─ convergence log
```

每轮至少记录 data term、regularizer、gradient norm、forward-projection residual 的空间分布和 wall time。只看总 loss 会掩盖 \(\lambda\) 变化：一个更平滑的结果可能 data mismatch 更大，却因 regularizer 降低而总 loss 更小。

伴随测试仍是底线。若 forward 与 adjoint 不匹配，梯度不再是所写目标的真实梯度；solver 可能下降缓慢、停在错误位置或对 step size 极端敏感。对自定义 CUDA projector，先做方向导数和伴随内积测试，再讨论高级正则。

FDK 可以作为 \(x^0\) 加速早期收敛，但不能改变最终目标。也可用 FDK 作为 preconditioner 的启发；真正的 preconditioning 要改善系统谱，而不是只提供一张看起来合理的初图。

## 7. 容易走错的岔路

“迭代重建一定优于 FDK”并不成立。若 forward model 不准确、regularizer 不适合任务或停止条件错误，迭代法会以更高成本得到更有偏的结果。FDK 仍是重要的可解释基线。

把 \(\lambda\) 调到图像最漂亮也不等于缺陷最可信。regularization 会改变小孔对比、边缘宽度和材料 CT number，应按任务指标和 phantom 校准。

data residual 越小越好同样危险。噪声本来就不应被完全拟合；若 residual 下降到噪声以下，算法很可能开始重建噪声和模型误差。

把缺失角度设为零测量而不是从 data term 中移除，会告诉算法“这些方向线积分为零”，产生错误约束。缺失数据应通过 mask/weight 表达。

最后，使用 autograd 不会自动保证 adjoint 高效或正确。通用反向传播可能保存巨大 ray intermediates；专用线性算子的伴随往往更省显存，也更容易做内积测试。

## 8. 本章落点、验证与下一章

本章从 FDK 无法消除的残差进入迭代重建。\(y=Ax+\varepsilon\) 给出 data fidelity，near-null-space 解释了仅拟合投影为何不稳定，regularizer 则在数据无法区分的方向上选择解。normal equation 和梯度明确展示了 forward、adjoint、measurement weights 与先验怎样共同作用。

在 CT Framework 中，本章对应统一 projector、objective 和 solver 接口；在 CTGS 中，Gaussian 参数代替 voxel \(x\)，但仍必须分别记录 measurement loss 与 representation regularization，不能把二者混成一个不可解释的 loss。

本章的 90 分钟验证是实现三 voxel 例子，扫描 \(\lambda\in\{0.01,0.1,1,10\}\)，对每个解记录 \(\|Ax-y\|\) 与 \(\|x\|\)。预期是 \(\lambda\) 增大时解范数下降、data residual 上升；\(\lambda\) 极小时系统重新接近非唯一。随后用随机向量验证 \(\langle Ax,r\rangle=\langle x,A^\ast r\rangle\)。

下一章会把二次正则的平滑偏差进一步暴露出来：为什么它会模糊真实边缘，total variation 如何用稀疏梯度保留分段常数结构，以及稀疏角和有限角中的零空间怎样决定任何先验能够恢复什么。
