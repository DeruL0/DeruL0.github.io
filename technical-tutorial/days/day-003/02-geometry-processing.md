# 几何处理第 3 章：为什么平滑会收缩，以及隐式求解究竟稳定了什么

## 1. 从一个真实任务开始

上一章从 Dirichlet energy 推出了 cotangent Laplacian，并用一次显式更新把五顶点网格的中心高度从 \(0.5\) 降到 \(0.3\)。现在把同一算子用于真实 CT 表面：网格有几百万个三角形，噪声尺度不同，局部最短边可能比平均边长小很多。我们希望连续平滑若干步，却发现小步长效果太慢，大步长出现振荡；即使数值稳定，闭合零件也不断变小。

这两个现象需要分开。振荡是时间离散化的稳定性问题，可以通过隐式积分解决；收缩是平均曲率流本身的几何性质，隐式方法不会自动消除。今天的任务就是把这两件事从同一套能量和线性系统中看清，并加入数据保真与约束，使“能运行的平滑”变成“知道自己改变了什么的去噪”。

## 2. 最直接的办法，以及它为什么不够

上一章的显式更新为

\[
X^{k+1}=X^k-\tau M^{-1}LX^k.
\]

最直接的加速办法是增大 \(\tau\)。对缓慢变化的低频形状，这会更快；对由短边支持的高频模式，更新量可能越过平衡位置，下一步再反向越过，于是产生正负振荡，最终发散。网格越细、最短边越小，允许的显式步长通常越苛刻。

另一个直接办法是多执行几百次小步长。这样可能稳定，却让球面半径持续下降、孔洞变窄、薄壁合拢。原因不是 cotangent 权重不够准确，而是热流作用在坐标函数上等价于平均曲率流：凸区域沿法向向内移动，曲面面积下降。噪声是高曲率，真实棱角和整个凸外壳也有曲率，纯扩散不会区分它们。

所以我们需要两个新工具。第一，用隐式时间步避免显式离散的步长爆炸；第二，把原始测量、边界、特征或体积作为约束写进目标，而不是指望“稳定”自动等于“保形”。

## 3. 关键想法是怎样被引出来的

显式方法在时刻 \(k\) 计算当前斜率，然后向前走一步；隐式方法要求新位置 \(X^{k+1}\) 自己满足扩散方程。高频模式越强，隐式方程对它的阻尼越强，因此不会因大步长反复越过零点。

更重要的是，隐式方程可以解释为一个最小化问题。新网格既不应离旧网格太远，又应降低 Dirichlet energy。把这两个要求放入同一个能量：

\[
E(X)
=
\frac12\|X-X^k\|_M^2
+
\frac{\tau}{2}X^{\mathsf T}LX.
\]

第一项是 data fidelity：按顶点代表的面积衡量移动；第二项是 smoothness：惩罚坐标在曲面上的快速变化。隐式更新不是一个神秘的数值技巧，而是这两个目标的平衡点。

一旦采用能量视角，保边界、保特征和保体积就不再是事后修补。它们可以作为固定自由度、额外惩罚或等式约束进入同一个系统。

## 4. 一步一步建立正式模型

对上面的能量求导。质量范数定义为

\[
\|X-X^k\|_M^2
=
(X-X^k)^{\mathsf T}M(X-X^k).
\]

令梯度为零，得到

\[
M(X^{k+1}-X^k)+\tau LX^{k+1}=0,
\]

也就是

\[
(M+\tau L)X^{k+1}=MX^k.
\]

为了看稳定性，把广义特征模式写成

\[
L\phi_i=\lambda_iM\phi_i,
\qquad \lambda_i\ge0.
\]

若当前形状在某个模式上的系数为 \(a_i^k\)，显式更新的放大因子是

\[
a_i^{k+1}
=
(1-\tau\lambda_i)a_i^k.
\]

当 \(\tau\lambda_i>2\) 时，幅值增大并发散；在 \(1<\tau\lambda_i<2\) 时符号也会交替。隐式更新则为

\[
a_i^{k+1}
=
\frac{1}{1+\tau\lambda_i}a_i^k.
\]

对任意 \(\tau>0\)，因子都位于 \((0,1]\)，所以每个非恒定模式都被衰减而不会翻转。这就是“无条件稳定”的具体含义。它不表示任意大步长都保持几何细节；大 \(\tau\) 会把高频直接压得很低，只是不会数值爆炸。

若要保持某些边界顶点，最直接的方法是把它们作为 Dirichlet constraints，从未知量中消去，或把对应矩阵行替换为单位行。若要软性靠近原始扫描表面 \(X^0\)，可加入

\[
\frac{\lambda}{2}\|X-X^0\|_M^2,
\]

系统变为

\[
[(1+\lambda)M+\tau L]X
=
MX^k+\lambda MX^0.
\]

闭合网格体积可以由有向三角形求和：

\[
V(X)
=
\frac16
\sum_{(i,j,k)\in F}
\mathbf x_i\cdot
(\mathbf x_j\times\mathbf x_k).
\]

在当前网格处线性化体积约束 \(V(X)=V_0\)，记梯度为 \(c=\nabla_XV\)，就能通过 KKT 系统同时求平滑位移和一个全局体积乘子。这样“保体积”是明确约束，而不是平滑后再随意缩放。

## 5. 跟着一个完整例子走到底

继续使用上一章的五顶点网格。四个边界点固定为 \(z=0\)，中心旧高度为 \(z^k=0.5\)。上一章已经得到

\[
M_{00}=0.8165,
\qquad
L_{00}=4\times0.8165=3.266.
\]

因为边界高度为零，中心的隐式方程在 \(z\) 方向简化为

\[
(0.8165+\tau\,3.266)z^{k+1}
=
0.8165\times0.5.
\]

取与上一章相同的 \(\tau=0.1\)，得到

\[
z^{k+1}
=
\frac{0.40825}{1.1431}
\approx0.3571.
\]

显式一步得到 \(0.3\)，隐式一步得到约 \(0.357\)。隐式方法不是“更强平滑”；同一个名义步长下，它按 \(1/(1+\tau\lambda)\) 阻尼，而显式按 \(1-\tau\lambda\) 阻尼，两种时间离散本来就不同。

现在故意取 \(\tau=1\)。显式更新根据上一章 \(\Delta z=-2\) 得到

\[
z^{k+1}_{\rm explicit}
=
0.5-2
=-1.5,
\]

中心直接穿过平面并翻到另一侧。隐式更新则为

\[
z^{k+1}_{\rm implicit}
=
\frac{0.40825}{0.8165+3.266}
=0.1.
\]

它仍在正确一侧，但高频凸起几乎被抹平。这正好区分稳定性与保真度。

若再加入 \(\lambda=4\) 的原始位置保真项，并取 \(\tau=1\)，中心方程为

\[
[(1+4)0.8165+3.266]z
=
(0.8165+4\times0.8165)0.5,
\]

解仍为 \(z=0.2778\)。平滑项想把中心压到平面，data term 则阻止它离原始几何过远；\(\lambda\) 的含义因此可以从能量直接解释。

## 6. 回到真实系统：程序实际上怎样工作

真实实现通常不会显式构造 \(M^{-1}L\)。直接组装对称稀疏矩阵 \(A=M+\tau L\)，对 \(x,y,z\) 三个右端分别求解，可以保持对称性并利用 sparse Cholesky 或 conjugate gradient。若 \(L\)、\(M\)、约束集合和 \(\tau\) 不变，分解可以复用多次。

模块结构可写成：

```text
DifferentialOperators {L, M}
→ ConstraintBuilder
   ├─ fixed boundary / feature vertices
   ├─ data attachment
   └─ optional volume constraint
→ SparseSystemAssembler
→ LinearSolver
→ geometry and volume diagnostics
```

若每一步都根据新位置重算 cotangent weights，这更接近非线性几何流，但矩阵也随时间变化；若固定初始 \(L\)，计算更便宜，却是在初始度量下扩散。二者都可用，必须在接口和实验记录中说明。

工程验证不能只看截图。应记录表面积、封闭体积、边界位移、Hausdorff distance 到原始网格，以及短边和翻转三角形数量。一个视觉上更光滑的结果可能已经损失孔径或壁厚。

## 7. 容易走错的岔路

“隐式方法无条件稳定”最容易被误解成“任意大步长都正确”。它只保证线性扩散模式不会数值发散；大步长仍会一次性删除真实细节。

把收缩归咎于显式 Euler 也不对。隐式方法同样沿平均曲率流降低面积，只是时间积分更稳定。要保体积必须添加约束或选择不同能量。

给所有顶点加入很大的 data weight 看起来能保形，但同时会让去噪几乎停止。data term 还应考虑扫描置信度：CT 表面在低对比、金属伪影和边界截断区域的可靠性不同，统一权重不一定合理。

平滑后全局缩放回原体积是一种简单补偿，但它会把所有方向同时放大，不能恢复局部孔径和薄壁。全局体积正确不代表局部尺寸正确。

最后，矩阵求解 residual 很小只证明线性方程解得准确，不证明离散算子、边界条件和几何目标正确。数值误差与建模误差必须分开检查。

## 8. 本章落点、验证与下一章

本章解释了显式平滑的步长限制和曲率流收缩为何是两类问题。广义特征模式揭示显式因子 \(1-\tau\lambda\) 会翻转，隐式因子 \(1/(1+\tau\lambda)\) 始终衰减；能量形式又让 data fidelity、固定边界和体积约束可以进入同一求解器。

在 CT mesh 管线中，本章对应 `SmoothingSolver`、约束构建和尺寸诊断。它应该输出的不只是新顶点，还包括面积、体积和到原始表面的偏移，供后续缺陷测量判断。

本章的 75 分钟验证是对五顶点例子分别运行 \(\tau=0.1\) 和 \(\tau=1\) 的显式、隐式更新，核对正文中的 \(0.3\)、\(0.357\)、\(-1.5\) 和 \(0.1\)。随后在一个闭合球网格上运行 20 步隐式流，记录表面积与体积。预期是求解始终稳定，但面积和体积单调下降，从而亲眼确认“稳定不等于保体积”。

下一章会解决曲率流仍然无法区分噪声和棱边的问题：先在法向空间识别同一平面与真实折线，再把过滤后的法向约束回顶点位置，构成保特征的 mesh denoising。
