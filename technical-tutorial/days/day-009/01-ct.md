# CT 第 9 章：几何参数错了时，为什么再好的重建算法也只是在解错题

## 1. 从一个真实任务开始

上一章讨论金属时，我们默认 source、detector、rotation axis 和每个 view angle 都已知。现在把对象换成一个工业微 CT 扫描：转台上放着带细孔的金属-树脂复合件，探测器是平板，X 射线源到转轴的距离、转轴到 detector 的距离、detector 横向偏移、detector 倾斜以及转轴是否垂直，都来自设备标称值。

真实工作不是“把投影丢进 FDK”。真实工作是先确认每条 detector pixel 对应空间中的哪条 X-ray，再把这组 rays 写进前向模型。如果 geometry 错了，测量本身没有坏，Beer-Lambert 也没有坏，但我们用错了 \(A\)。这类错误会表现为双边缘、圆孔变椭圆、细丝变粗、截面中心漂移，甚至在迭代重建中被正则化错误地解释成模糊或非物理材料。

今天的任务是把几何标定放回 CT 的物理链条：从实际采集装置定义坐标系，到 detector pixel 生成 ray，再到系统矩阵 \(A(g)\)，最后把几何参数 \(g\) 作为需要估计和验证的对象，而不是隐藏在重建代码里的常量。

## 2. 最直接的办法，以及它为什么不够

最直接的方法是相信设备说明书。设 source-to-axis distance、source-to-detector distance 和 detector pixel size 都等于 nominal value，转台每步转过同样角度。这样可以很快构造 FDK projector，并且在大块均匀物体上通常能得到“看起来还行”的图像。

失败会出现在高分辨率或高几何精度任务里。假设 detector 水平方向相对 rotation axis 偏了 1 个 pixel。每个 view 的投影都会带着一个固定横向误差；反投影时，同一个物理点从不同角度被投回略不同的位置。模糊不是后处理造成的，而是所有 rays 在三维空间中没有相交到同一个物点。若再用 TV 或神经场去拟合，它们只能在错误几何下寻找一个折中体，结果可能更平滑，却不更真实。

另一个直接办法是在重建图像里调 center-of-rotation，直到视觉最清楚。这对单个水平偏移有用，但 geometry 不是一个标量。source 轨迹偏心、detector 倾斜、view angle jitter、转轴不垂直、非圆轨迹都会让简单 COR 调参失效。需要把“重建图像不清楚”追溯到“projection operator 的几何参数不确定”。

## 3. 关键想法是怎样被引出来的

第一个关键观察是：投影算子不是固定的 \(A\)，而是由几何参数生成的 \(A(g)\)。如果 \(g\) 包括 source position、detector center、detector basis、view angle 和 pixel pitch，那么第 \(i\) 条 ray 的路径随 \(g\) 改变。重建误差的一部分不属于 \(x\)，而属于 \(g\)。

第二个观察是：几何标定需要可观测对象。最常见的是 calibration phantom，例如若干钢珠、钢丝或已知几何的 3D 打印标定件。它们在三维中的位置已知或可同时估计，在每个 projection 上形成容易定位的二维特征。把三维点投到 detector 后，预测中心与实测中心之间的 reprojection residual 就直接约束 geometry。

第三个观察是 gauge freedom。若同时任意缩放物体、source-detector 距离和 voxel size，某些投影位置可能保持近似不变。因此标定必须固定坐标单位、转轴定义或 phantom 尺寸。否则优化器会给出低 residual 但物理无意义的参数。

近年的低成本 CT 与移动 CT 仍然把这个问题作为核心工程环节。例如 2026 年一篇开源摘要可见的工作用带钢球的 3D 打印 phantom 和迭代优化估计 source-object-detector geometry，并报告亚像素级残差；这说明几何标定不是老设备才有的问题，而是可复现实验系统的基础条件。[From radiography to CT: Geometric calibration using a 3D-printed phantom](https://www.sciencedirect.com/science/article/pii/S2590123026001817)

## 4. 一步一步建立正式模型

先从一条 cone-beam ray 开始。对第 \(j\) 个 view，source position 记为

\[
s_j(g)\in\mathbb R^3.
\]

detector 不是一个抽象平面，而是由中心点和两个单位方向决定。中心点为

\[
c_j(g)\in\mathbb R^3,
\]

水平方向和竖直方向为

\[
u_j(g),\ v_j(g)\in\mathbb R^3.
\]

若 detector pixel 坐标为 \((m,n)\)，pixel pitch 为 \(\Delta_u,\Delta_v\)，detector 上对应点可写成

\[
d_{jmn}(g)
=
c_j(g)
+(m-m_0)\Delta_u u_j(g)
+(n-n_0)\Delta_v v_j(g).
\]

这一步的意义是把“第几行第几列 detector”变成三维空间中的一个点。穿过物体的 ray 由 source 和 detector point 决定：

\[
r_{jmn}(t;g)
=
s_j(g)
+t\left[d_{jmn}(g)-s_j(g)\right],
\qquad t\ge 0.
\]

若体素衰减系数为 \(x\)，沿该 ray 的线积分是

\[
(A(g)x)_{jmn}
=
\int_{\text{ray}(j,m,n;g)} \mu(x')\,ds.
\]

计数模型因此变成

\[
\lambda_{jmn}(x,g)
=
b_{jmn}
\exp\left[-(A(g)x)_{jmn}\right]
+r_{jmn}.
\]

当 \(g\) 固定时，这是前几章的重建问题；当 \(g\) 不确定时，应该写成联合估计：

\[
(\widehat x,\widehat g)
=
\arg\min_{x,g}
\left[
D\big(n\mid \lambda(x,g)\big)
+\beta R(x)
+\gamma P(g)
\right].
\]

这里 \(P(g)\) 是几何先验，例如距离不能偏离设备标称值太多、view-to-view 变化应平滑、detector basis 应保持正交。若有 fiducial points \(X_k\) 和每个 view 的二维检测位置 \(y_{jk}\)，还可以直接最小化 reprojection residual：

\[
E_{\rm cal}(g)
=
\sum_{j,k}
\left\|
\pi_j(X_k;g)-y_{jk}
\right\|_2^2.
\]

\(\pi_j\) 表示由 \(s_j,c_j,u_j,v_j\) 决定的透视投影。这个公式出现的原因很具体：我们不想等到三维重建模糊后才猜错因，而是在二维 detector 上直接比较“已知三维标记应该落在哪里”。

## 5. 跟着一个完整例子走到底

先看二维平行束中的 center offset，因为它能清楚展示 \(A(g)\) 为什么会错。设物体中有一个小钢珠，真实坐标为

\[
X=(a,b)=(10,0)\ {\rm mm}.
\]

第 \(\theta\) 个 view 的理想 detector 坐标为

\[
p(\theta)=a\cos\theta+b\sin\theta.
\]

如果 detector 相对 rotation axis 固定偏移 \(\delta=1\ {\rm mm}\)，实际观测变成

\[
p_{\rm obs}(\theta)
=
a\cos\theta+b\sin\theta+\delta.
\]

取四个角度 \(0^\circ,90^\circ,180^\circ,270^\circ\)，观测位置为

\[
[11,\ 1,\ -9,\ 1]\ {\rm mm}.
\]

若重建程序假设 \(\delta=0\)，它期待同一钢珠的 sinogram 是

\[
[10,\ 0,\ -10,\ 0]\ {\rm mm}.
\]

差值不是随机噪声，而是每个 view 都带着同一个 detector offset。利用相对角度 \(180^\circ\) 的对称性，可以估计

\[
\widehat\delta
=
\frac{p_{\rm obs}(0^\circ)+p_{\rm obs}(180^\circ)}{2}
=
\frac{11+(-9)}{2}
=1.
\]

同样，

\[
\frac{p_{\rm obs}(90^\circ)+p_{\rm obs}(270^\circ)}{2}
=1.
\]

减去 \(\widehat\delta\) 后得到

\[
[10,\ 0,\ -10,\ 0],
\]

这时钢珠的轨迹才与同一个三维点一致。这个小例子只估计了一个 detector offset，但逻辑已经完整：已知三维点产生可预测二维轨迹；几何参数错误使轨迹整体偏移或变形；标定通过最小化轨迹残差恢复 \(g\)。

在 cone-beam 中，钢珠轨迹不再只是正弦，而是由透视投影和 detector 平面姿态共同决定。多个钢珠、多个高度、多个 view 能让 source-detector distance、detector tilt 和 rotation axis 偏差分别变得可观测。若只放一个位于中心的钢珠，很多参数仍会互相混淆。

## 6. 回到真实系统：程序实际上怎样工作

一个可靠的工业 CT 系统应把 geometry 当成一等数据。采集时保存 nominal geometry、温度或设备状态、每个 view 的 encoder angle、detector bad-pixel 状态和 phantom 或工件坐标系。标定阶段检测 fiducial center，估计 \(g\)，记录 reprojection residual 的均值、最大值和按 view 的分布。重建阶段使用同一份 geometry JSON 或数据库记录生成 projector，而不是在多个模块里复制散落常量。

在 CT Framework 中，`ProjectorGeometry` 不应只包含 voxel spacing 和角度数组，还应能表达 source pose、detector pose、pixel pitch、principal point、rotation axis、per-view perturbation 和参数是否参与优化。前向投影、反投影和伴随测试必须使用同一个 geometry 实例；否则即使数值矩阵看似相同，也会出现梯度与物理 ray 不一致。

对 CTGS，geometry 更敏感。Gaussian attenuation 的位置和尺度由优化决定，若 geometry 错了，训练会把系统误差吸收到 Gaussian centers 中。短期看 loss 下降，长期看换角度渲染、尺寸测量和 mesh extraction 都会偏。更稳的做法是在训练前做 phantom 标定；若要 joint optimization，应先固定低维 \(g\)，加入强先验，并用独立 phantom 或重复扫描验证，而不是让所有 view 的 pose 全自由。

实际标定也需要分层。第一层是离线 phantom calibration，估计设备固定参数；第二层是每次扫描的 center-of-rotation 和对象 pose；第三层才是更细的 per-view jitter。越往后自由度越高，越容易被图像先验误导。

## 7. 容易走错的岔路

把几何问题当成图像锐化问题很诱人，因为调 unsharp mask 或 TV 权重能让边缘看起来更硬。但它没有让 rays 重新对准物理空间，尺寸和 projection consistency 仍会错。

只调 center-of-rotation 也常见。COR 是最容易观察的几何误差之一，但 detector tilt、source sag、rotation-axis wobble 和 view angle jitter 会产生不同的残差形状。一个标量调到图像最清楚，不等于几何已标定。

让每个 view 都有完全自由的 6DoF pose 似乎最通用，但对普通工件几乎不可辨识。优化器可以用 pose 抖动解释噪声、材料误差或金属伪影，得到低 loss 的假几何。应从低维、物理合理、可重复的参数开始。

忽略标定的不确定性也危险。若 fiducial 检测误差是 0.2 pixel，最终 voxel 级误差不可能无限小。工程报告应同时给出 reprojection residual、重建后尺寸误差和独立验证物的结果。

最后，不要把厂商 nominal geometry 当成真值，也不要把一次 phantom calibration 当成永久真值。微焦点源热漂移、机械加载、探测器安装和转台维护都会改变几何；高精度工业 CT 需要周期性复测。

## 8. 本章落点、验证与下一章

本章把 CT 几何从隐藏常量提升为 \(A(g)\)。当 \(g\) 错时，重建不是噪声大，而是 forward model 选错；fiducial reprojection residual 提供了直接估计 geometry 的途径，联合重建则必须受强先验和可观测性约束。

在你的 CT 与 CTGS 项目中，本章对应 geometry 配置、phantom 标定、differentiable projector 的几何参数接口、projection consistency 评估和尺寸验证。不要让 neural representation 或 regularizer 吞掉几何错误。

本章的 90 分钟验证是实现二维平行束 offset 例子：生成一个点 \(X=(10,0)\) 在四个角度下的投影，加入 \(\delta=1\) mm，分别用未校正和校正后的投影做简单反投影或 least-squares 定位。预期是未校正时点的位置不能由四条约束一致确定，校正后 residual 降到零；再把 \(\delta\) 改成随角度正弦变化，观察单一 COR 无法完全解释。

下一章将进入运动补偿。几何标定假设扫描期间工件是刚体且相对转台不动；如果对象或装置随时间运动，\(g\) 固定也不够，必须让物体状态或几何状态随 projection time 变化。
