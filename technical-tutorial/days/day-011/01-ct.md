# CT 第 11 章：学习先验怎样进入迭代重建，而不是替代物理模型

## 1. 从一个真实任务开始

上一章把运动写进 CT 前向模型：第 \(j\) 个 projection 测量的是 \(A_jW_{t_j}x_0\)，而不是同一个静态 \(Ax\)。现在假设几何、运动和计数模型都已经尽量正确，仍然会遇到另一个困难：低剂量、稀疏角、金属残留和材料边界让逆问题病态，单靠手写 TV 或 Tikhonov 先验很难同时保住细裂纹、孔隙和低对比结构。

真实任务是重建一块多孔材料。我们知道 X-ray 从 source 到 detector 的物理链条，知道 count likelihood，也知道工业检测最关心小孔、裂纹和薄壁。但在 60 个 views 的低剂量扫描中，FBP 有强条纹；普通 TV 把孔壁磨圆；纯图像去噪网络能让图像漂亮，却可能制造不存在的孔或抹掉真实缺陷。

今天的问题不是“用深度学习替代 CT 重建”。更准确的问题是：怎样把学习到的图像先验放进一个仍然尊重 projection data 的迭代结构里，让网络在物理一致性之外补充先验，而不是绕过测量模型。

## 2. 最直接的办法，以及它为什么不够

最直接的方法是先用 FBP 或迭代法重建，再用 CNN 去噪。这很容易部署，因为网络只处理图像。但它看到的是已经被错误反投影和有限角零空间污染的图像。网络不知道哪些结构有 projection 支持，哪些只是重建伪影。若训练集偏向某类材料，它还可能把真实异常修成“正常纹理”。

第二个方法是直接从 sinogram 到 image 训练一个大网络。它能在 benchmark 上很强，但物理约束被隐藏进网络参数。几何、dose、detector binning、材料和扫描轨迹稍有变化，网络就可能失效。对工业 CT，这种域外风险很难接受。

第三个方法是继续调手写正则化。TV、Huber、wavelet 和 nonlocal priors 各有价值，但它们表达能力有限。孔隙材料、金属边界和复合材料的真实先验很难用一个凸函数完整描述。

于是关键抽象出现了：保留 data-consistency step，把学习模块放在 prior 或 proximal 位置；每一次更新都回到投影模型检查，而不是让网络一次性决定最终图像。

## 3. 关键想法是怎样被引出来的

经典迭代重建可看作交替处理两件事。第一件事是让当前图像解释测量数据；第二件事是让图像符合某种先验。若 log-domain 近似为

\[
y=Ax+\epsilon,
\]

可以写成

\[
\widehat x
=
\arg\min_x
\frac12\|Ax-y\|^2+\beta R(x).
\]

近端梯度一步先做 data step：

\[
z^k=x^k-\alpha A^{\mathsf T}(Ax^k-y),
\]

再做 prior step：

\[
x^{k+1}=\operatorname{prox}_{\alpha\beta R}(z^k).
\]

Plug-and-Play 的关键想法是：如果 prior step 本质上像去噪，是否可以把 proximal operator 替换成一个真实 denoiser：

\[
x^{k+1}=D_{\sigma}(z^k).
\]

这样 forward model 和 denoiser 被解耦。PnP 最早就是为了把成像系统的前向模型与强去噪器结合起来，而不是为每个 denoiser 写出显式正则项。[Plug-and-Play Priors for Model Based Reconstruction](https://engineering.purdue.edu/~bouman/Plug-and-Play/webdocs/GlobalSIP2013a.pdf)

深度展开则走另一条路：把固定次数的迭代写成网络层，每一层保留 \(A\)、\(A^{\mathsf T}\) 或 primal-dual 更新，但把 step size、proximal block 或 correction block 学出来。Learned Primal-Dual 是典型例子：它直接把 tomography forward operator 放进学习的 primal-dual 迭代结构中。[Learned Primal-Dual Reconstruction](https://pubmed.ncbi.nlm.nih.gov/29870362/)

## 4. 一步一步建立正式模型

先从真实 count model 出发。对第 \(i\) 条 ray，

\[
\lambda_i(x)=b_i\exp[-(Ax)_i]+r_i.
\]

Poisson negative log-likelihood 可写成

\[
D(x)
=
\sum_i
\left[
\lambda_i(x)-n_i\log \lambda_i(x)
\right].
\]

普通梯度迭代是

\[
z^k=x^k-\alpha_k\nabla D(x^k).
\]

若我们有显式正则项 \(R\)，则下一步是

\[
x^{k+1}
=
\operatorname{prox}_{\alpha_k\beta R}(z^k)
=
\arg\min_x
\frac{1}{2\alpha_k}\|x-z^k\|^2+\beta R(x).
\]

PnP 把这个 proximal step 替换成 denoiser：

\[
x^{k+1}=D_{\sigma_k}(z^k).
\]

这一步的含义是：data step 负责把图像推向 projection consistency；denoiser 负责把图像推向训练数据中常见的结构集合。它不要求 \(D_\sigma\) 一定来自某个显式 \(R\)，但也因此需要额外关心收敛和不确定性。

在 ADMM 形式中，引入变量 \(v\)，约束 \(x=v\)：

\[
\min_{x,v} D(x)+\beta R(v)
\quad\text{s.t.}\quad x=v.
\]

迭代中 \(x\)-update 处理 CT data term，\(v\)-update 是 proximal 或 denoiser：

\[
v^{k+1}=D_\sigma(x^{k+1}+u^k).
\]

深度展开则把每一步改成可学习函数。例如

\[
x^{k+1}
=
G_{\theta_k}
\left(
x^k,
A^{\mathsf T}H_{\theta_k}(Ax^k,y)
\right).
\]

\(H_{\theta_k}\) 学习 projection-domain correction，\(G_{\theta_k}\) 学习 image-domain update。重要的是 \(A\) 和 \(A^{\mathsf T}\) 仍在网络内部，而不是被一张黑箱图像翻译网络替代。

## 5. 跟着一个完整例子走到底

用三条 ray、两个 voxel 的小系统看 PnP 的工作方式。设

\[
A=
\begin{bmatrix}
1&0\\
0&1\\
1&1
\end{bmatrix},
\qquad
y=
\begin{bmatrix}
1.2\\
0.1\\
1.4
\end{bmatrix}.
\]

从

\[
x^0=
\begin{bmatrix}
0\\
0
\end{bmatrix}
\]

开始。先算 data residual：

\[
Ax^0-y=
\begin{bmatrix}
-1.2\\
-0.1\\
-1.4
\end{bmatrix}.
\]

梯度为

\[
A^{\mathsf T}(Ax^0-y)
=
\begin{bmatrix}
-2.6\\
-1.5
\end{bmatrix}.
\]

取 step size \(\alpha=0.1\)，data step 给出

\[
z^0=x^0-0.1
\begin{bmatrix}
-2.6\\
-1.5
\end{bmatrix}
=
\begin{bmatrix}
0.26\\
0.15
\end{bmatrix}.
\]

如果不加先验，下一步就是这个 \(z^0\)。现在用一个简单 denoiser 模拟“相邻 voxel 不应差异过大但也不应完全相等”：

\[
D(z)_1=0.8z_1+0.2z_2,
\qquad
D(z)_2=0.2z_1+0.8z_2.
\]

于是

\[
x^1=D(z^0)
=
\begin{bmatrix}
0.238\\
0.172
\end{bmatrix}.
\]

这个 denoiser 把两个 voxel 拉近，但没有抹成同一个值。下一轮仍会重新计算 \(Ax^1-y\)，把结果拉回测量一致性。若直接对 FBP 图像去噪，只会执行一次 \(D\)，不会再用第三条 ray \(x_1+x_2\approx1.4\) 检查输出。

这个小例子也显示 PnP 的风险：如果 denoiser 过强，把两个 voxel 总是拉成相等，它会压制真实材料边界。data step 和 denoiser 权重必须通过 projection residual 与任务指标共同选择。

## 6. 回到真实系统：程序实际上怎样工作

一个可控的 CT PnP pipeline 应显式保存每次迭代的 data residual、denoiser strength、projection residual 和图像变化量。不能只比较最终 PSNR。工业 CT 更应报告缺陷检测指标、孔径误差、材料边界误差和对未知异常的保真度。

训练 denoiser 或展开网络时，最重要的是数据域匹配。若训练集只包含干净医学切片，直接用于工业多材料 CT 会把纹理先验带错。更稳妥的做法是合成与真实物理接近的 degradation，保留 forward model，或用自监督/noise2noise/重复扫描构造更贴近项目的数据。

在 CT Framework 中，PnP 模块应像一个 `PriorOperator`，接口接收当前 volume、噪声尺度和 metadata，输出候选 volume；reconstruction loop 仍拥有 \(A\)、\(A^{\mathsf T}\)、count likelihood 和 constraints。这样可以替换 TV、wavelet、BM3D 或 neural denoiser，而不重写 projector。

在 CTGS 中，学习先验可以作用于体素 density、Gaussian attenuation 参数、材料 label 或 extracted surface。要小心不要把 denoiser 当作 ground truth。若 PnP 先验使 projection residual 变差却图像更平滑，它可能正在把真实缺陷修掉。

## 7. 容易走错的岔路

第一个误区是把 PnP 当成普通后处理。PnP 的关键是每次 denoising 后回到 data consistency；只做一次图像去噪不具备这个闭环。

第二个误区是认为 denoiser 越强越好。强先验能消除伪影，也能消除真实异常。工业检测中，罕见结构往往是最重要的结构。

第三个误区是忽略收敛。任意神经网络 denoiser 不一定对应非扩张映射或显式正则项；迭代震荡、固定点偏移和 hallucination 都需要监控。

第四个误区是把训练集指标等同于任务质量。PSNR 高的 reconstruction 可能在小裂纹 recall 上更差。任务型评估应和 projection consistency 一起报告。

最后，深度展开不是越深越好。更多 unrolled steps 增加显存、训练难度和对固定扫描协议的绑定。若几何或 dose 改变，过度特化的展开网络可能比传统迭代更脆弱。

## 8. 本章落点、验证与下一章

本章说明学习先验应进入迭代重建的 prior/proximal 位置，而不是替代 CT 物理模型。Data step 使用 \(A\)、\(A^{\mathsf T}\) 或 Poisson likelihood 保持测量一致；PnP 用 denoiser 代替 proximal；深度展开把有限步迭代变成可训练网络，但仍保留 forward operator。

在你的 CT 与 CTGS 项目中，本章对应可插拔 prior operator、projection residual 监控、denoiser 强度调度、展开网络与 projector 的接口，以及任务型缺陷评估。

本章的 90 分钟验证是复现两 voxel 三 ray 的例子：实现 data step、简单邻域 denoiser 和 5 次 PnP 迭代；同时记录 \(\|Ax-y\|\) 与 \(\|x^{k+1}-x^k\|\)。预期是 denoiser 会平滑 voxel 差异，但每轮 data step 会继续拉回第三条 ray 的一致性；把 denoiser 权重调到 0.5 以上会明显损害数据残差。

下一章将进入不确定性与任务型质量评价。学习先验越强，越需要回答“哪些结构可信、哪些可能是先验生成的”；这不能只靠图像观感，而要把重建不确定性和具体检测任务联系起来。
