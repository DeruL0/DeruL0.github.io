# CT 第 8 章：金属为什么会把局部测量错误扩散成整幅图像的条纹

## 1. 从一个真实任务开始

上一章把单能 Beer-Lambert 模型扩展成了多能谱 count model。即使 spectrum 和 scatter 已经建模，扫描含钢螺钉、钨合金或厚铜件的工业零件时，仍会看到从金属边缘向外放射的亮暗条纹。它们不是金属附近几个 voxel 的局部误差，而会穿过整个截面。

今天的任务是重建一个树脂壳体中的两枚钢螺钉。普通树脂射线仍有上千个 photons；穿过两枚螺钉的射线只剩零到几个 counts，有些 detector channels 还达到电子学下限或饱和。我们必须先判断这些数值究竟是低信噪观测、只知道范围的删失观测，还是完全缺失的观测，然后再决定它们是否应进入 reconstruction objective。

这一步是金属伪影校正的物理起点。所谓 MAR 并不是一种固定滤波器，而是对“metal trace 中还剩下多少可信信息”作出不同假设后形成的一组方法。

## 2. 最直接的办法，以及它为什么不够

最直接的做法是像处理普通 projection 一样计算

\[
p_i=-\log\frac{n_i-r_i}{b_i}.
\]

当 \(n_i-r_i\) 接近零时，负对数会趋向无穷。工程代码通常把它 clamp 到一个很大的有限值。这样虽然避免了数值异常，却把“detector 只报告了下限”伪装成了一条精确线积分。相邻 detector bins 之间随即出现巨大跳变。

另一种直接做法是重建后在图像域平滑条纹。条纹由错误 projection 经反投影产生，方向与 acquisition geometry 有关；图像滤波无法知道哪一条射线最初失真，往往同时抹掉螺纹、裂纹和薄壁。

还可以把 metal trace 全部删除，再用左右邻居线性插值。它确实能减小 projection 的尖锐断裂，但插值值不是实际穿过金属的衰减。若金属后面有真实边缘，插值会把边缘跨过去，产生 secondary artifacts。直接方法的共同问题，是没有区分观测机制与补全假设。

## 3. 关键想法是怎样被引出来的

先在初始重建中分割 metal volume \(x_M\)，再用同一几何前向投影：

\[
t_i=(A x_M)_i.
\]

若 \(t_i>0\)，第 \(i\) 条 ray 穿过金属。所有这些 detector-angle samples 组成 metal trace

\[
\mathcal M=\{i\mid t_i>0\}.
\]

这个 trace 把图像域的金属位置映射回真正发生 photon starvation 的 measurement domain。接下来不应立刻决定“插值还是不插值”，而要给每条射线一个观测状态。

若 count 足够高，它是普通 Poisson sample；若电子学只能报告 \(n_i\le c\)，它是左删失 sample，我们知道真实 count 落在一个区间；若 detector pixel 坏掉或 projection 被截断，则没有 count likelihood；若只是方差很大，可以保留观测但降低权重。由此得到的关键抽象是：金属问题首先是带 mask、权重或 censoring 的统计逆问题，其次才是补全问题。

## 4. 一步一步建立正式模型

从 count domain 开始。多能 expected count 仍写成

\[
\lambda_i(x)
=
\sum_k s_{ik}
\exp\left[-(A\mu_k(x))_i\right]+r_i.
\]

对于可靠射线集合 \(\mathcal V\)，Poisson data term 为

\[
D_{\mathcal V}(x)
=
\sum_{i\in\mathcal V}
\left[
\lambda_i(x)-n_i\log\lambda_i(x)
\right].
\]

如果第 \(i\) 个 detector 只能确认 count 不超过下限 \(c_i\)，正确事件不是 \(N_i=c_i\)，而是 \(N_i\le c_i\)。它的 likelihood 为

\[
P(N_i\le c_i\mid\lambda_i)
=
\sum_{q=0}^{c_i}
\frac{e^{-\lambda_i}\lambda_i^q}{q!}.
\]

相应负对数项是

\[
D_i^{\rm censored}(x)
=
-\log P(N_i\le c_i\mid\lambda_i(x)).
\]

这保留了“expected count 应该很低”的信息，却不会声称 detector 精确测到了 \(c_i\)。对完全缺失的 rays，不写 data term，而由其余 rays 与 regularizer 约束：

\[
\widehat x
=
\arg\min_{x\ge0}
\left[
D_{\mathcal V}(x)
+D_{\mathcal C}^{\rm censored}(x)
+\beta R(x)
\right].
\]

解析 FBP 不能方便地接受这种非均匀 likelihood，因此经典 MAR 常先构造完成后的 sinogram。设 log projection 为 \(p\)，binary metal mask 为 \(m_i\)。最简单的线性补全在同一 view 中寻找 metal trace 左右边界 \(a,b\)：

\[
\widetilde p_j
=
p_a+
\frac{j-a}{b-a}(p_b-p_a),
\qquad a<j<b.
\]

Normalized MAR 不直接插值原始 \(p\)，而先从初始图像生成只包含软组织或背景趋势的 prior projection \(p^{\rm prior}\)，计算归一化 sinogram

\[
q_i=\frac{p_i}{p_i^{\rm prior}+\epsilon},
\]

只对 \(q\) 的 metal trace 插值，再恢复

\[
\widetilde p_i
=
\widetilde q_i p_i^{\rm prior}.
\]

这样补全主要传递相对偏差，不会让插值跨越所有低频解剖结构。它仍是数据假设，而不是恢复了真正金属测量。

## 5. 跟着一个完整例子走到底

考虑某一个 view 的六个 detector samples。已校正的 log projection 为

\[
p=[0.20,\ 0.30,\ \text{无效},\ \text{无效},\ 0.80,\ 0.90].
\]

前向投影 metal segmentation 后发现第 3、4 个 samples 属于 metal trace。若把零 count clamp 后得到 \(p_3=p_4=8\)，局部二阶差分会非常大。例如在第 2 至第 4 点附近，

\[
p_2-2p_3+p_4
=0.30-16+8=-7.70.
\]

FBP 的 ramp filter强调这种高频不连续，因此该错误会沿第 3、4 条 ray 的反投影路径扩散成条纹。

现在使用边界 \(a=2,b=5\) 做线性补全。第 3、4 点分别为

\[
\widetilde p_3
=0.30+\frac13(0.80-0.30)
\approx0.4667,
\]

\[
\widetilde p_4
=0.30+\frac23(0.80-0.30)
\approx0.6333.
\]

完成后的序列是

\[
\widetilde p
=[0.20,\ 0.30,\ 0.4667,\ 0.6333,\ 0.80,\ 0.90].
\]

同一位置的二阶差分变成接近零：

\[
0.30-2(0.4667)+0.6333
\approx0.
\]

因此 ramp filter不再放大人为尖峰，条纹会明显减轻。但若真实物体在第 3 点后有一个树脂到空气的边界，0.4667 仍只是平滑猜测。更严格的 iterative reconstruction 会保留第 1、2、5、6 个可靠 samples 的 likelihood，把第 3、4 个位置交给 nonnegativity、TV 或材料 prior，而不是把插值值当成同等可信的测量。

最后需要把 metal 本身恢复到结果中。常见流程用补全 sinogram重建非金属背景，再将可信的 metal segmentation重新组合；否则补全会把金属也变成连续背景。

## 6. 回到真实系统：程序实际上怎样工作

一个可诊断的工业 MAR pipeline 应显式保存每个中间状态：

~~~text
raw counts, dark field and flat field
→ saturation / underflow / bad-pixel flags
→ initial count-aware reconstruction
→ metal segmentation with uncertainty margin
→ forward project metal to obtain metal trace
→ classify reliable, noisy, censored and missing rays
→ sinogram completion or masked/censored likelihood
→ reconstruct non-metal background
→ restore metal and run consistency checks
~~~

metal segmentation 的轻微误差会在 projection domain 放大。trace 太窄会留下污染 rays，太宽会删除本来有效的数据，因此常对 segmentation 做小范围 dilation，并扫描 dilation width 对结果的影响。

在 CT Framework 中，mask 不应只是一个悄悄把 residual 乘零的 tensor。每条 ray 的状态、阈值来源和最终 data term 都应进入日志；重建后还要把结果 forward-project 回原始可靠 counts，检查 MAR 是否只改善了视觉却恶化了数据一致性。

在 CTGS 中，可让 Gaussian attenuation 通过多能 projector直接预测 counts，并对 reliable、censored 与 missing rays使用不同 loss。若先用神经网络补全 sinogram，再把补全值当 ground truth训练 CTGS，网络的 hallucination 会被写进三维表示。更稳妥的做法是把补全值作为低权重 prior，并保留原始 count likelihood。

现代 learned MAR 常在 sinogram、image 或二者之间交替学习 correction，但它们仍必须遵守 metal trace 与 forward consistency。研究方法真正增加的是数据先验，而不是绕过观测模型。

## 7. 容易走错的岔路

把 metal trace 内所有 rays 一律删除过于粗糙。边缘只穿过少量金属的 rays 可能仍有可用 counts；完全 photon-starved 的 rays 与高噪 rays不应使用同一权重。

把插值 sinogram 当作真实数据会造成过度自信。补全区域应保留 provenance mask，评价时分别报告 measured region 与 completed region 的 residual。

仅凭重建图中高灰度阈值分割 metal 会受 beam hardening 和 partial volume影响。应检查 segmentation 的 forward projection是否覆盖实际异常 detector bins。

用一个强 TV regularizer消除条纹可能同时消除真实薄裂纹。正则化不能替代观测状态分类，尤其在工业 CT 中，最重要的缺陷往往正是小而高频的结构。

最后，视觉上最平滑的 MAR 未必最准确。过强补全很容易制造完整但虚假的边界，必须用无金属区域误差、已知 phantom dimensions、projection consistency和重复扫描共同验证。

## 8. 本章落点、验证与下一章

本章解释了金属伪影为何从局部 detector failure 变成全图条纹：clamp 后的异常 log values 经 ramp filter放大，再沿 ray paths反投影。metal segmentation 的 forward projection给出 metal trace；可靠、删失和缺失观测应分别进入普通 likelihood、区间 likelihood 或先验约束。

在 CT 与 CTGS 项目中，本章对应 detector-quality flags、metal-trace projector、masked/censored loss、MAR provenance和 forward-consistency evaluation，而不是单一的“去条纹”后处理按钮。

本章的 90 分钟验证是用正文六点 sinogram构造一个简单平行束 phantom：分别把 metal samples设为 8、线性插值和从 objective 中 mask，观察 ramp-filtered projection与反投影。预期是 clamp方案产生最大振铃，插值方案最平滑但改变金属路径，masked iterative方案对 regularizer最敏感；所有方案都应在可靠 rays上重新计算 residual。

下一章将处理几何标定误差。即使每条 count 都有效，只要 source、detector、rotation axis 或 view angle与 projector不一致，\(A\) 本身就是错的；届时需要从 fiducials、投影一致性或联合优化中估计 geometry parameters。
