# 几何处理第 2 章：怎样把连续曲面的曲率变成网格上的矩阵

## 1. 从一个真实任务开始

上一章把 STL triangle soup 整理成了具有可靠一环邻域的离散曲面。现在考虑一个常见的 CT 后处理任务：Marching Cubes 提取出的表面带有体素台阶和高频噪声，我们希望把这些小尺度起伏压低，同时尽量保留零件的整体形状、薄壁和边界。

这个任务表面上叫“平滑”，实际需要回答更深的问题。连续曲面上的平滑通常由扩散、曲率和能量描述；网格只有离散的顶点与三角形。程序怎样知道一个顶点偏离了局部曲面多少？又怎样让采样密集和采样稀疏的区域遵守同一种几何规律？

这就是离散微分几何的第一项工作：不是给顶点套一个经验平均，而是把连续曲面上的梯度、散度和 Laplace-Beltrami operator 翻译成由网格几何决定的稀疏矩阵。今天先完成其中最重要的一步：cotangent Laplacian。

## 2. 最直接的办法，以及它为什么不够

既然上一章已经能找到顶点 \(i\) 的一环邻居 \(N(i)\)，最直接的平滑是把顶点移向邻居平均：

\[
\mathbf x_i^{\rm new}
=
(1-\lambda)\mathbf x_i
+
\lambda\frac{1}{|N(i)|}
\sum_{j\in N(i)}\mathbf x_j.
\]

对规则、近似等边三角形组成的平面网格，它的确能压低锯齿。但它只看“是否相邻”，完全不看三角形的角度和面积。把同一块平面用不同对角线剖分，邻接关系发生变化，平均结果也会变化；在一个顶点周围放很多很短的边，这一区域便获得比稀疏区域更大的数值影响。

更严重的是收缩。对一个闭合曲面，每个顶点都被拉向邻居平均，球会越来越小，尖锐结构会越来越钝。收缩并非实现 bug，而是这类更新实际上在做离散扩散；如果我们不知道它对应什么连续过程，也就无法判断步长、边界条件或体积变化是否合理。

因此，问题不只是“平均权重该调成多少”。我们需要一个满足几何一致性的算子：常数函数不应产生变化，线性函数在平面内部应尽量被正确再现，三角形大小应通过积分面积进入模型，而且算子最好来自一个明确能量，这样稳定性和优化问题才能被分析。

## 3. 关键想法是怎样被引出来的

连续平面上的 Laplacian 可以写成二阶导数之和；在曲面上没有统一的全局 \(x,y\) 坐标，所以更自然的定义是“先求曲面梯度，再求散度”：

\[
\Delta_{\mathcal M} f
=
\operatorname{div}_{\mathcal M}
\nabla_{\mathcal M}f.
\]

这个定义告诉我们，Laplacian 测量的是一个位置相对于周围值的净流量。若 \(f\) 在局部是常数，没有方向存在梯度，净流量应为零；若一个顶点值高于周围，扩散应把它向下推。

直接在每个不规则三角形上近似二阶导数并不方便。更稳健的路线是先考虑 Dirichlet energy：

\[
E(f)
=
\frac12
\int_{\mathcal M}
\|\nabla_{\mathcal M}f\|^2\,dA.
\]

这个能量惩罚相邻位置之间的快速变化。对分片线性三角网格，\(f\) 在每个三角形内部的梯度是常数，因此能量可以逐三角形精确积分。把所有三角形贡献组装起来，就会自然出现 cotangent 权重。换句话说，cotangent 不是为了比均匀平均“更高级”而选出的经验公式，而是三角形上线性基函数梯度做内积后的几何系数。

这里还会出现第二个对象：面积矩阵 \(M\)。稀疏矩阵 \(L\) 记录相邻顶点之间的变化能量，\(M\) 记录每个顶点代表多少曲面面积。没有 \(M\)，同一个函数在密集网格和稀疏网格上的数值尺度不会一致。

## 4. 一步一步建立正式模型

设标量函数 \(f\) 只在网格顶点上给出，三角形内部用重心坐标线性插值。对一条内部边 \((i,j)\)，它两侧三角形中与该边相对的角记为 \(\alpha_{ij}\) 和 \(\beta_{ij}\)。有限元组装得到边权重

\[
w_{ij}
=
\frac12
\left(
\cot\alpha_{ij}+
\cot\beta_{ij}
\right).
\]

边界边只有一个相对角，就只保留对应的一项。采用正半定号约定时，离散 stiffness matrix 的作用写成

\[
(Lf)_i
=
\sum_{j\in N(i)}
w_{ij}(f_i-f_j).
\]

这个定义立即给出两个正确性条件。因为每一项都是差值，常数向量满足

\[
L\mathbf 1=0.
\]

又因为内部边对两个端点使用同一权重，\(L\) 是对称矩阵。在没有退化和异常边界处理时，能量可以写成

\[
E(f)
=
\frac12 f^{\mathsf T}Lf
=
\frac14
\sum_{(i,j)}
(\cot\alpha_{ij}+\cot\beta_{ij})
(f_i-f_j)^2.
\]

但 \(Lf\) 仍然是“按顶点累积的积分量”，还没有除以顶点代表的面积。最简单的 lumped mass 是把每个相邻三角形面积的三分之一分给顶点：

\[
M_{ii}
=
\frac13
\sum_{t\ni i} A_t.
\]

若采用连续算子 \(\Delta=\operatorname{div}\nabla\) 的负半定约定，则

\[
\Delta_{\mathcal M}f
\approx
-M^{-1}Lf.
\]

符号约定在不同库中并不统一，所以不能只看函数名 `laplacian`。可靠做法是检查矩阵对角线、\(L\mathbf1\) 和一个凸起顶点的更新方向。

把三个坐标函数一起写成顶点矩阵 \(X\in\mathbb R^{n\times3}\)，有

\[
\Delta_{\mathcal M}X
\approx
-M^{-1}LX.
\]

它与平均曲率法向量成比例；常见约定下 \(\Delta X=-2H\mathbf n\)，具体正负取决于法向和 Laplacian 定义。重要的工程含义是：\(M^{-1}LX\) 不只是“邻居平均差”，它给出了由局部三角形角度和面积标定的弯曲方向。

显式 heat-flow 平滑于是写成

\[
X^{k+1}
=
X^k-\tau M^{-1}LX^k.
\]

当 \(\tau\) 太大时，最高频模式会被过度更新，产生振荡甚至发散。隐式形式把下一时刻放入右侧算子：

\[
(M+\tau L)X^{k+1}
=
MX^k.
\]

它需要解稀疏线性系统，但对较大步长更稳定。两者做的是同一个扩散过程，不是两种没有关系的平滑技巧。

## 5. 跟着一个完整例子走到底

构造一个由四个三角形组成的小网格。中心顶点略微凸起：

\[
v_0=(0,0,0.5),
\]

四个边界顶点为

\[
v_1=(1,0,0),\quad
v_2=(0,1,0),\quad
v_3=(-1,0,0),\quad
v_4=(0,-1,0).
\]

三角形依次为 \((0,1,2)\)、\((0,2,3)\)、\((0,3,4)\)、\((0,4,1)\)。我们固定边界，只更新中心。

每个三角形的两条边向量可以取为 \((1,0,-0.5)\) 和 \((0,1,-0.5)\)。叉积长度为 \(\sqrt{1.5}\)，所以每个三角形面积为

\[
A_t=\frac{\sqrt{1.5}}{2}\approx0.6124.
\]

对中心到任意边界顶点的边，两侧相对角的 cotangent 都约为 \(0.8165\)。因此这条内部边的权重为

\[
w_{0j}
=
\frac12(0.8165+0.8165)
=0.8165.
\]

中心顶点的 lumped mass 是四个相邻三角形面积的三分之一：

\[
M_{00}
=
\frac{4\times0.6124}{3}
\approx0.8165.
\]

由于四个边界顶点的 \(x,y\) 对称，中心在水平方向的 Laplacian 为零。只看高度 \(z\)，有

\[
(Lz)_0
=
\sum_{j=1}^{4}
0.8165(0.5-0)
\approx1.633.
\]

于是连续符号下的离散 Laplacian 为

\[
(\Delta z)_0
\approx
-\frac{1.633}{0.8165}
=-2.
\]

取显式步长 \(\tau=0.1\)，一次更新得到

\[
z_0^{\rm new}
=
0.5+0.1(-2)
=0.3.
\]

中心向周围平面下降，而 \(x,y\) 不动。这不是因为程序被告知“凸起是噪声”，而是凸起使坐标函数的 Dirichlet energy 增大，曲率流沿能量下降方向移动它。若整个网格所有高度同时加 10，差值不变，更新也不变；这正是 \(L\mathbf1=0\) 的实际含义。

## 6. 回到真实系统：程序实际上怎样工作

实现时，输入必须是上一章验证过的 indexed manifold mesh。程序逐三角形计算面积和三个 cotangent，再把局部 \(3\times3\) stiffness contribution 累加到全局 sparse matrix。质量矩阵可以先用 barycentric lumping；在对数值精度要求更高时，再考虑 Voronoi area 或一致质量矩阵。

一个清晰的模块边界是：

```text
ValidatedSurface
→ DifferentialOperatorBuilder
   ├─ sparse stiffness matrix L
   ├─ mass matrix M
   └─ boundary mask
→ Smoothing / Curvature / PDE solver
→ updated vertex positions
→ recompute normals and diagnostics
```

每次组装后至少检查 \(L\) 是否近似对称、\(L\mathbf1\) 是否接近零、质量对角线是否为正。面积接近零的三角形会让 cotangent 爆大；非流形边会让“两侧相对角”的定义失去唯一性。这解释了为什么拓扑和退化诊断必须发生在微分算子之前。

对 CT 提取表面，还应区分采样噪声与真实薄结构。Laplacian smoothing 会同时降低二者的高频能量。实际系统常加入边界固定、特征边约束、法向引导、双边权重或数据保真项，而不是无限次运行纯扩散。libigl 的离散几何教程也把 cotangent matrix、mass matrix 和 curvature 放在同一个算子体系中，便于直接对照实现。[libigl tutorial](https://libigl.github.io/tutorial/)

## 7. 容易走错的岔路

把均匀 graph Laplacian 叫作“Laplacian”并不算数学错误，但它主要编码连接关系，不会自动逼近曲面的 Laplace-Beltrami operator。在三角形非常规则时二者可能相似，一旦网格密度和角度变化，结果便依赖剖分。

看到 cotangent 权重便假设它们都为正也不安全。钝角三角形的 cotangent 可以为负，算子仍来自有限元能量，但局部最大值性质和某些平滑直觉可能失效。若算法依赖非负权重，需要 Delaunay 化或选择其他离散方案，而不能偷偷把负权重截成零后仍声称保持同一算子。

显式更新运行一次看起来正常，不代表任意步长都安全。高分辨率网格的最短边更小，最高频特征值更大，同样的 \(\tau\) 可能在新网格上振荡。步长应由谱半径、边长尺度或隐式求解控制。

只在最后重算法线也不能修复错误的顶点更新。法线是几何变化后的派生量；它可以让光照看起来更平滑，却不会恢复已经收缩的薄壁或被移动的边界。

最后，曲率大不等于噪声。零件棱边、孔口和薄壁本来就有高曲率。纯曲率流没有语义，会把这些结构与台阶一起消除。

## 8. 本章落点、验证与下一章

本章把上一章获得的一环邻域变成了第一个真正的离散微分算子。cotangent 权重来自三角形分片线性函数的 Dirichlet energy，\(L\) 衡量相邻值的变化，\(M\) 把累积量按曲面面积归一化，\(-M^{-1}L\) 近似 Laplace-Beltrami operator。把它作用在顶点坐标上，就得到与平均曲率法向相关的变形方向。

在 CT mesh 项目中，`DifferentialOperatorBuilder` 应位于 STL 修复之后、平滑和曲率估计之前。对 STL/DirectX 查看器，GPU 仍只需要更新后的 vertex/index buffer；cotangent 和 sparse solve 属于 CPU 几何内核，不应塞入渲染数据结构。

本章的 60 分钟验证是实现上面的五顶点网格，组装 \(L\) 与 lumped \(M\)。先验证 \(\|L\mathbf1\|\) 接近零、\(L\) 对称，再固定边界执行一次 \(\tau=0.1\) 的显式更新。按本章权重，中心高度应从 \(0.5\) 降到约 \(0.3\)，水平坐标保持零。随后把所有顶点高度加 10，更新量应不变。

下一章会处理今天已经看见但尚未解决的收缩：为什么平均曲率流天然减少面积，怎样用隐式系统获得稳定时间步，以及数据保真、边界条件和体积约束怎样把“数值上平滑”变成“几何上可用的去噪”。
