# CT 第 6 章：为什么低剂量 CT 不能把所有投影误差当成同一种噪声

## 1. 从一个真实任务开始

上一章在负对数投影域中使用平方 data term 和 TV 正则。高剂量下，探测器每个 pixel 收到的光子很多，负对数后的噪声可以近似为小幅 Gaussian；但工业扫描为了缩短时间、降低热负荷或穿透高衰减金属，会出现一些 rays 收到上千光子，另一些只收到个位数甚至零光子。

今天的真实任务是重建一个厚金属零件。薄区测量稳定，厚区 photon-starved。若把所有负对数 residual 等权处理，厚区的巨大随机波动会与薄区的精确测量拥有相同影响，条纹会从低计数 rays 向整个体传播。

要修复这个问题，必须回到探测器真正测到的对象：不是连续线积分，而是离散光子计数。Beer-Lambert 决定计数均值，Poisson distribution 描述在这个均值下实际会数到多少 photons，统计重建再从 likelihood 推导 data fidelity。

## 2. 最直接的办法，以及它为什么不够

最直接的预处理仍是

\[
\widehat p_i
=
-\log\frac{n_i}{b_i},
\]

其中 \(b_i\) 是无物体时的 incident count，\(n_i\) 是穿过物体后的 count。随后最小化

\[
\frac12\|Ax-\widehat p\|_2^2.
\]

当 \(n_i\) 很大时，这很合理。但负对数是非线性变换。计数波动相同的一个 photon，在 \(n_i=1000\) 时影响很小，在 \(n_i=2\) 时会造成巨大 log 变化；当 \(n_i=0\) 时，负对数甚至无定义。

简单给零计数加 1 可以让程序运行，却人为规定了最大线积分，并让结果依赖 arbitrary offset。更根本的问题是，负对数后的不同 rays 方差不同。等权平方误差假设它们同样可靠，这与 photon counting 过程矛盾。

## 3. 关键想法是怎样被引出来的

对固定曝光，光子逐个到达 detector。若到达事件近似独立，某个 pixel 的 count 可建模为 Poisson random variable。它的均值和方差都等于期望 count：

\[
n_i\sim\operatorname{Poisson}(\lambda_i),
\qquad
\operatorname{Var}(n_i)=\lambda_i.
\]

Beer-Lambert 给出期望 count 与线积分的关系。忽略 scatter 时：

\[
\lambda_i(x)
=
b_i\exp[-(Ax)_i].
\]

厚区的 \((Ax)_i\) 大，\(\lambda_i\) 小，相对噪声

\[
\frac{\sqrt{\lambda_i}}{\lambda_i}
=
\frac{1}{\sqrt{\lambda_i}}
\]

自然变大。统计模型因此不会把所有 log residual 当成同方差，而是直接问：当前 \(x\) 预测的 count distribution 产生观测 \(n_i\) 的可能性有多大？

## 4. 一步一步建立正式模型

Poisson probability 为

\[
P(n_i\mid\lambda_i)
=
\frac{\lambda_i^{n_i}e^{-\lambda_i}}{n_i!}.
\]

最大化所有 pixels 的 likelihood，等价于最小化忽略与 \(x\) 无关常数后的 negative log-likelihood：

\[
D_{\rm P}(x)
=
\sum_i
\left[
\lambda_i(x)
-n_i\log\lambda_i(x)
\right].
\]

先忽略 scatter，令

\[
p_i=(Ax)_i,
\qquad
\lambda_i=b_ie^{-p_i}.
\]

对预测线积分求导：

\[
\frac{\partial D_{\rm P}}{\partial p_i}
=
n_i-\lambda_i.
\]

再通过 \(p=Ax\) 返回体空间：

\[
\nabla_xD_{\rm P}(x)
=
A^{\mathsf T}[n-\lambda(x)].
\]

这个 residual 位于 count domain。若预测 count 太高，即 \(\lambda_i>n_i\)，梯度会推动对应线积分增大；若预测 count 太低，则推动线积分减小。

二阶曲率为

\[
\frac{\partial^2D_{\rm P}}{\partial p_i^2}
=
\lambda_i,
\]

所以高计数 ray 对目标具有更强局部曲率，提供更精确约束；低计数 ray 的 likelihood 更平缓。加权 least squares 的常用近似正来自这里：负对数投影的方差约与 \(1/n_i\) 成正比，因此权重可与 count 相关。

加入背景或 scatter expectation \(r_i\) 后：

\[
\lambda_i(x)
=
b_i e^{-(Ax)_i}+r_i.
\]

此时 data gradient 不再简化为 \(n_i-\lambda_i\)，而是

\[
\frac{\partial D_{\rm P}}{\partial p_i}
=
(\lambda_i-r_i)
\left(
\frac{n_i}{\lambda_i}-1
\right).
\]

这说明 scatter 不是在 log projection 上减一个常数就能完全处理；它改变了 likelihood 与梯度。

最终统计重建仍可加入先验：

\[
\min_{x\ge0}
D_{\rm P}(x)+\beta R(x).
\]

TV、二次正则或 learned prior 选择解，Poisson term 则更准确地表达测量可信度。

## 5. 跟着一个完整例子走到底

考虑两条穿过相同材料厚度的 rays，真实线积分都是

\[
p=2.
\]

第一条 ray 的 incident count 为 \(b_1=10000\)，期望 transmitted count 为

\[
\lambda_1
=
10000e^{-2}
\approx1353.35.
\]

假设实际观测 \(n_1=1350\)。负对数估计为

\[
\widehat p_1
=
-\log(1350/10000)
\approx2.0025,
\]

非常接近真实值。

第二条 ray 只有 \(b_2=100\)，期望 count 为

\[
\lambda_2
=
100e^{-2}
\approx13.53.
\]

若随机观测 \(n_2=10\)，负对数估计变成

\[
\widehat p_2
=
-\log(10/100)
\approx2.3026.
\]

两条 ray 穿过同一厚度，但低计数 ray 的 log error 大约 0.30。等权 least squares 会把它当成与高计数 ray 同等可靠的线积分偏差。

现在在候选 \(p=2.2\) 处比较 Poisson gradient。预测 counts 为

\[
\lambda_1=10000e^{-2.2}\approx1108.0,
\]

\[
\lambda_2=100e^{-2.2}\approx11.08.
\]

count-domain derivatives 为

\[
n_1-\lambda_1
\approx242.0,
\]

\[
n_2-\lambda_2
\approx-1.08.
\]

高曝光 ray 强烈表明候选衰减过大，低曝光 ray 只提供弱而相反的随机证据。Poisson likelihood 按实际统计信息自动形成这种差异。

若第二条 ray 观测为零，log transform 失效；Poisson term仍是有限的

\[
D_2=\lambda_2,
\]

并继续提供“预测 count 应更低”的梯度。它不需要人为把零替换成 1，但 detector saturation、dark current 和 censoring 仍要用更完整模型处理。

## 6. 回到真实系统：程序实际上怎样工作

统计重建管线应保留 raw count、blank scan 和校正元数据，而不是只保存最终 log sinogram：

~~~text
raw counts n
incident/flat counts b
dark current and detector calibration
scatter/background estimate r
→ expected count model lambda(x)
→ Poisson likelihood and gradient
→ regularized constrained solver
→ count-domain residual diagnostics
~~~

数值实现必须避免直接计算极小 \(\lambda\) 的 log。对 \(\lambda\) 设置物理合理的正下界，使用稳定指数，并区分真正零计数、坏 pixel 和被截断测量。坏 pixel 应从 likelihood mask 中移除，而不是解释为零 photons。

count-domain goodness-of-fit 不能只看普通 residual。Poisson deviance 能比较观测与预测在其方差尺度下是否合理；还应按 detector 区域、view 和 estimated count 分桶检查，寻找 scatter、beam hardening 或 calibration 引起的结构化偏差。

CTGS 若直接拟合负对数 projection，通常仍使用近似 Gaussian loss；低剂量场景可以让 Gaussian attenuation 参数先生成 line integral，再通过 \(b e^{-p}+r\) 转到 expected counts，使用同一 Poisson likelihood。这样观测模型与表示模型保持分离。

## 7. 容易走错的岔路

Poisson 模型并不表示所有 CT 噪声都只有 shot noise。readout noise、gain variation、scatter uncertainty、detector lag 和 preprocessing correlation 仍可能存在；Poisson 是更接近起点的模型，不是完整终点。

把观测 count \(n_i\) 直接当权重会在 \(n_i=0\) 时完全丢弃 ray，也会产生 data-dependent bias。更稳健的方法使用预测 count、经过修正的权重或直接优化 likelihood。

零 count 不等于“无限衰减已被精确测到”。它只表示这次曝光未检测到 photons，能提供的是单侧且有限的统计证据。

增加 \(\beta R(x)\) 后 likelihood 上升不一定是失败，因为先验有意牺牲 data fit；但应检查 residual 是否仍与计数统计相符，而不是只看总 objective。

最后，如果 beam hardening 使单能 Beer-Lambert 模型错误，再精确的 Poisson solver 也会把模型误差重建成结构。统计正确性不能替代物理正确性。

## 8. 本章落点、验证与下一章

本章从低剂量 photon starvation 重新建立了 CT data fidelity。incident count 经 Beer-Lambert 得到 expected transmitted count，Poisson likelihood 直接处理异方差与零计数；其梯度 \(A^{\mathsf T}(n-\lambda)\) 把 count-domain 误差返回体空间。高计数 rays 自然具有更强统计约束。

在 CT Framework 中，本章对应 count-preserving dataset、expected-count forward model、Poisson objective 和 deviance diagnostics。在 CTGS 中，Gaussian projector 仍输出衰减线积分，统计层再把它变成 expected counts，二者不应混在一个 kernel 里。

本章的 90 分钟验证是模拟两组相同 phantom 投影，incident counts 分别为 \(10^4\) 和 \(10^2\)，采样 Poisson counts 后比较等权 log-domain least squares、count-weighted least squares 与 Poisson likelihood。预期是低剂量 log projection 出现明显异方差和零值问题，而 Poisson 模型在 count domain 保持有限并减少 photon-starved rays 对条纹的过度影响。

下一章会处理本章最后暴露的模型误差：真实 X 射线是多能谱，材料衰减随能量变化，scatter 还会向 detector 增加非路径积分 photons。束硬化、散射与多材料模型为什么会破坏单能线性关系，将成为下一问题。
